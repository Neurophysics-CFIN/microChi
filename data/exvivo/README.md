# Local ex vivo inputs

Place these six MATLAB files here: `DWI_FBI.mat`, `Phase_map.mat`,
`mask_phase.mat`, `mask_wm.mat`, `mask_csf.mat`, and `meta_info.mat`.

See [the guide](../../docs/reconstruction_tutorial.md) for variable names,
shapes, units, optional weights, reference NIfTI requirements, and commands.
The original DWI file is about 506 MiB; distribute it separately from ordinary
Git commits. Confirm that you have permission to share data and that applicable
privacy requirements are met before distributing it. Keep local data backed
up independently.
